# AGENTS.md

Инструкции по установке инструментов для студентов Хекслета, общие для всех курсов. Правки идут прямо в `main`.

## Версии

Каждая версия в правленом файле сверяется с источником, включая ОС и дистрибутив WSL. Номер из памяти модели считается гипотезой, потому что модель отстаёт от релизов.

- Последний цикл и поддержка берутся из `curl -s https://endoflife.date/api/v1/products/<продукт>`, у Ubuntu и Node.js смотри последнюю LTS (`isLts`).
- После правки прогони `python3 scripts/check-versions.py .`. Новая версия в тексте без правила в `.github/versions.json` получает правило там же, иначе еженедельная проверка её не увидит.
- Команды без номера версии (`brew install postgresql`) проверка не ловит. Пиши версию явно, если пакетный менеджер это позволяет.

## Команды и выводы

Команды для Linux прогоняются в контейнере каждой поддерживаемой LTS Ubuntu (`docker run --rm ubuntu:<версия>`), выводы в статье снимаются с реальной версии инструмента. Шаги, которые запустить нельзя (macOS, WSL), сверяются с документацией проекта, и в отчёте пользователю они перечисляются как непроверенные.
